# Basic Gross Pay Calculator 💵

## Description
A simple Python script designed to calculate an employee's total gross pay based on their hours worked and hourly rate. This version handles straightforward multiplication without complex conditional logic (like overtime).

## Context
This project was created as an exercise for Chapter 2 of the "Programming for Everybody (Getting Started with Python)" course from the University of Michigan on Coursera. It served as my introduction to using variables, receiving user input, and performing basic arithmetic operations in Python.

## Skills Demonstrated
* **User Input:** Using the `input()` function to interact with the user.
* **Type Casting:** Converting string inputs into floating-point numbers (`float()`) to allow for mathematical operations.
* **Basic Arithmetic:** Utilizing the multiplication operator (`*`) to compute the final pay.

## Usage
Run the script in your terminal and enter the numeric values when prompted:
